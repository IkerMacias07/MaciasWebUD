# MaciasWebUD

## Descripción
Aplicación web desarrollada en Java con JSF (JavaServer Faces) 
para la Universidad Distrital Francisco José de Caldas.

## Funcionalidades
- Simulador de CDT (Certificado de Depósito a Término)
- Registro de Aspirantes a programas académicos

## Tecnologías usadas
- Java
- JSF (JavaServer Faces)
- Maven
- Apache Tomcat v10.1
- Eclipse IDE

## Estructura del proyecto (MVC)
- **Modelo:** asp.modelo, cdt
- **Vista:** archivos .xhtml (cdt.xhtml, asp.xhtml, index.xhtml)
- **Controlador:** asp.bean, cdt.bean
